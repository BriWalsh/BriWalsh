# Brian Walsh

Principal Delivery Consultant at [Liatrio](https://liatrio.com). I lead delivery for AI-assisted engineering work and build the tooling that makes it repeatable.

I work from one idea, **Prove Then Scale**: run an experiment, deliver a thin slice, prove it with evidence, then scale what held up.

## What I'm working on

- **AI gateways.** I help build [State of AI Gateways](https://ai-gateway.liatr.io/), Liatrio's public comparison of enterprise AI gateways. It looks at identity, policy, spend, routing and observability. My own reading notes are in [ai-gateway-notes](https://github.com/BriWalsh/ai-gateway-notes).
- **Agent workflows.** I write Cursor and cloud-agent skills that close daily delivery loops. They are draft-only, with a person approving anything that goes out. See [brwalsh](https://github.com/BriWalsh/brwalsh) and the sanitized [cursor-skills-public](https://github.com/BriWalsh/cursor-skills-public).
- **Client delivery.** Most of my day-to-day code is private client and Liatrio work: agent skills, delivery automation, and platform tooling. I don't publish it.

## How I work

- Experiment, deliver, prove. Each step produces something someone can check.
- Agents draft and people send.
- Sensitive content stays out of prompts unless a gate allows it.
- Ship a small v0.1 that fixes one problem, then iterate.
