## How I work

- **Dogfood first** — If we recommend a gateway or agent pattern, we run it ourselves.
- **Human-in-the-loop by default** — Agents draft; people send.
- **Fail closed on sensitive data** — Client content stays out of prompts unless gated for real.
- **Smallest shippable wound-closer** — v0.1 that solves one pain, roadmap for the rest.
- **Evidence over theater** — Minutes saved, friction logged, citations on claims.
